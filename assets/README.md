# Imagens do site

Coloca nesta pasta as imagens otimizadas e com utilização autorizada:

- `capa-curso.jpg`: fotografia vertical de unhas de gel e fibra para o destaque do hero e poster do vídeo; o texto alternativo atual descreve o tema.
- `video-curso.mp4`: vídeo de apresentação/trecho do curso. A secção só aparece quando este ficheiro existe no alojamento.
- `curso-unhas-social.jpg`: imagem de partilha para redes sociais, idealmente 1200 × 630 px. Atualiza também o domínio placeholder nos metadados Open Graph e Twitter.
- `favicon.svg`: ícone do site, já incluído nesta pasta.

Usa imagens comprimidas, dimensões adequadas e evita fotografias sem licença. Se `capa-curso.jpg` não existir, o destaque apresenta um fundo de recurso em CSS.
