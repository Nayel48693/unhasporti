Esta política explica como são tratados os dados pessoais associados à utilização deste site. Este é um site independente de divulgação de um curso e não é o site oficial nem o vendedor do curso.

Responsável pelo tratamento

O responsável pelo tratamento dos dados é [PREENCHER: nome ou denominação legal], com morada em [PREENCHER: morada] e contacto através de [PREENCHER: endereço de e-mail]. Preenche estes dados antes de publicar.

Que dados são tratados

Este site não disponibiliza formulários de registo nem recolhe dados para criar uma conta. Se contactares o responsável por e-mail, os dados incluídos na mensagem e os dados de contacto serão tratados para responder ao pedido. A infraestrutura de alojamento poderá registar dados técnicos, como o endereço IP, data, hora e páginas consultadas, para disponibilizar e proteger o site.

Finalidades e fundamentos

Os dados de uma mensagem são tratados para responder ao teu pedido e, quando aplicável, com base em diligências pré-contratuais ou no interesse legítimo de gerir a comunicação. Dados técnicos poderão ser tratados para segurança, funcionamento e diagnóstico do alojamento, de acordo com o interesse legítimo do responsável e do fornecedor.

Cookies e tecnologias semelhantes

O site utiliza o armazenamento local do navegador para guardar a tua escolha relativa a cookies de análise e publicidade. Esta preferência é guardada no dispositivo com a chave unhasporti-cookie-consent. Os píxeis da Meta e do TikTok, e o Google Analytics, só são carregados se aceitares e se o respetivo identificador estiver preenchido na configuração do site. Se recusares, estes serviços não são carregados por este site. Podes alterar ou apagar os dados locais nas definições do navegador; ao fazê-lo, a pergunta de consentimento poderá voltar a aparecer.

As fontes tipográficas são solicitadas aos Google Fonts. Esse pedido pode transmitir dados técnicos, como o endereço IP, ao fornecedor, segundo as respetivas políticas. Os botões de afiliado conduzem a um site externo, sujeito à política de privacidade do respetivo operador. Consulta essas políticas antes de forneceres dados nesses sites.

Destinatários e transferências

Os fornecedores de alojamento e, apenas após consentimento, os fornecedores das ferramentas de análise e publicidade poderão tratar dados nos termos das suas políticas e condições. Alguns fornecedores podem tratar dados fora do Espaço Económico Europeu. Consulta a documentação de cada fornecedor para conheceres as garantias aplicáveis.

Prazo de conservação

As mensagens serão conservadas apenas durante o tempo necessário para responder e cumprir obrigações legais aplicáveis. Os registos técnicos seguem os prazos definidos pelo fornecedor de alojamento. A preferência de consentimento permanece no teu navegador até ser removida ou substituída.

Os teus direitos
